# Monthly scenario assumptions

The decision-support scenario is restricted to **Gurugram / Payments Operations / June 2026 opened requests**. Workload and capacity use the same monthly period.

- 1,600 assigned FTEs (explicit modelling assumption for this high-volume service scope)
- 160 productive hours per FTE per month
- 82% utilisation, giving 1,049.6 productive capacity hours
- 15% processing-time improvement, configurable in the dashboard
- ₹130 per overtime hour
- ₹250,000 one-time implementation cost
- Only avoided overtime is monetised; released capacity is not treated as automatic cash saving
- Payback is implementation cost divided by monthly avoided overtime cost and is omitted when savings are zero

All outputs are synthetic modelled opportunities, not realised corporate savings.
