# KPI dictionary

| KPI | Definition | Grain |
|---|---|---|
| SLA compliance | Closed requests with turnaround <= SLA target / closed requests | Request |
| Average TAT | Mean turnaround hours for closed requests | Request |
| Backlog | Requests with status Open at extract date | Request |
| Operating cost | Sum of simulated request processing costs | Request |
| Quality score | Mean simulated quality score | Request |

All financial values are INR and synthetic.
